# Project screenshots

Drop one image per project here, named by its index in the work section:

    01.png   XOFram
    02.png   Netflix Clone
    03.png   Agentic Starter Kit

`.png`, `.jpg`, `.jpeg` and `.webp` all work. Anything around 1600px wide is
plenty; Astro re-encodes and downscales at build time, so do not optimise first.

A project with no image here simply renders without one. Nothing breaks, and
there is no empty slot left on the page.
